## Installation

### Clone the Repository

```bash
git clone https://github.com/pj74ncoding/responsive-bootstrap-application.git
cd responsive-bootstrap-application


```

### Install Dependencies

Frontend:

```bash
cd responsive-bootstrap-application


npm install
```

### Run Development Servers

Frontend:

```bash
npm start
```
